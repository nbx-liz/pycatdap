# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |
| Previous minor | Best effort |

## Reporting a Vulnerability

**Do not open a public issue.**

Use [GitHub Security Advisories](https://github.com/nbx-liz/pycatdap/security/advisories/new)
to report vulnerabilities privately.

We will acknowledge reports within 48 hours and provide a timeline for resolution.
